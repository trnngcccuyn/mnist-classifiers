# Báo cáo (10–15 trang)

Đặt file nguồn và `report.pdf` ở đây. Dàn ý:

1. Giới thiệu
2. Dữ liệu
3. Phương pháp (công thức + pseudocode cho từng mô hình)
4. Thí nghiệm (thiết lập, siêu tham số)
5. Kết quả (bảng độ đo, confusion matrix, biểu đồ)
6. Thảo luận (ưu/nhược điểm: độ chính xác, thời gian huấn luyện, thời gian dự đoán, khả năng giải thích)
7. Kết luận
8. Tài liệu tham khảo
9. Phân công công việc trong nhóm
